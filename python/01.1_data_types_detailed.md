# Python Data Types - Detailed Study (Hinglish) 🐍

## ❓ Data Type Kya Hota Hai?

**Data Type** batata hai ki kisi variable ke andar kis tarah ki value store hai. 

Variable ko ek **dabba (container)** samjho, aur **Data Type** batata hai ki us dabbe ke andar kya rakha hai—jaise numbers, text, ya true/false values.

---

## 📂 Python ke Data Types Aur Unka Real-World Website Use-Case 🌐

Real websites (jaise Amazon, Netflix, Instagram) me ye data types kahan aur kaise use hote hain, aaiye aasan Hinglish me samajhte hain:

### 1. Integer (`int`)
**Whole Numbers** (bina decimal wale numbers).
*   **Real Website Use-case:** 
    *   Shopping cart me items ki quantity (jaise `cart_items = 3`).
    *   Kisi post par likes ka count (jaise `likes = 1205`).
    *   User ki Unique ID (`user_id = 459821`).
*   **Code:**
    ```python
    age = 20
    print("INTEGER:", age, type(age))
    ```

### 2. Float (`float`)
**Decimal Numbers** (point wale numbers).
*   **Real Website Use-case:** 
    *   Product ki price (jaise `price = 99.99`).
    *   Netflix movie ki average rating (jaise `rating = 4.8`).
    *   GPS location coordinates (jaise latitude `28.6139`).
*   **Code:**
    ```python
    price = 99.99
    print("FLOAT:", price, type(price))
    ```

### 3. String (`str`)
**Text (akshar ya words)**.
*   **Real Website Use-case:** 
    *   User ka naam (`username = "Rahul"`).
    *   Login email address (`email = "rahul@example.com"`).
    *   Search bar me type kiya gaya keyword (`query = "best laptop under 50k"`).
*   **Code:**
    ```python
    name = "Rahul"
    print("STRING:", name, type(name))
    ```

### 4. Boolean (`bool`)
Sirf do values hoti hain: **`True`** ya **`False`**.
*   **Real Website Use-case:** 
    *   User logged in hai ya nahi (`is_logged_in = True`).
    *   Website par Dark Mode active hai ya nahi (`dark_mode_on = False`).
    *   Product stock me hai ya out of stock (`in_stock = True`).
*   **Code:**
    ```python
    logged_in = True
    print("BOOLEAN:", logged_in, type(logged_in))
    ```

---

### 5. List (`list`)
Multiple values ka ordered collection (Mutable - values badli ja sakti hain).
*   **Real Website Use-case:** 
    *   Cart me items ke names (`cart_list = ["Laptop", "Mouse", "Keyboard"]`).
    *   Kisi blog post ke tags (`tags = ["tech", "python", "coding"]`).
*   **Code:**
    ```python
    fruits = ["Apple", "Banana", "Mango"]
    fruits.append("Orange") # List me naya item add kiya
    print("LIST:", fruits, type(fruits))
    ```

### 6. Tuple (`tuple`)
Ordered collection jo **Immutable** hoti hai (values nahi badli ja sakti).
*   **Real Website Use-case:** 
    *   Website brand colors ke RGB values (`brand_color = (255, 0, 0)`).
    *   Map coordinates (Latitude, Longitude) jo change nahi hone wale (`coordinates = (28.6139, 77.2090)`).
*   **Code:**
    ```python
    resolution = (1920, 1080)
    print("TUPLE:", resolution, type(resolution))
    ```

### 7. Set (`set`)
**Sirf unique values** (duplicates nahi hote).
*   **Real Website Use-case:** 
    *   Active online visitors ki IDs ka unique collection taaki repeat count na ho.
    *   Unique interest groups jo kisi user ne select kiye hain.
*   **Code:**
    ```python
    skills = {"Python", "SQL", "Python"}
    print("SET:", skills, type(skills)) # Output me duplicate Python automatic gayab ho jayega
    ```

### 8. Dictionary (`dict`)
**Key-Value pairs** ke roop me data store karna.
*   **Real Website Use-case:** 
    *   User ka Profile Data (jaise database se user info aana):
        ```python
        user_profile = {
            "name": "Rahul",
            "email": "rahul@gmail.com",
            "is_premium": True
        }
        ```
*   **Code:**
    ```python
    student = {
        "name": "Rahul",
        "age": 20,
        "marks": 95
    }
    print("DICTIONARY:", student, type(student))
    ```

---

### 9. None (`NoneType`)
Khali (empty) value.
*   **Real Website Use-case:** 
    *   Optional fields jo user ne abhi tak fill nahi kiye (jaise `middle_name = None`).
    *   Discount coupon code agar user ne apply nahi kiya (`applied_coupon = None`).
*   **Code:**
    ```python
    result = None
    print("NONE:", result, type(result))
    ```

### 10. Bytes (`bytes`) & Bytearray (`bytearray`)
Binary data representation (mutable/immutable).
*   **Real Website Use-case:** 
    *   Website par upload hone wali image ya profile picture ka raw binary data.
    *   Network request se aane wale raw data packets.
*   **Code:**
    ```python
    b = b"ABC"
    ba = bytearray(b"ABC")
    print("BYTES:", b, type(b))
    print("BYTEARRAY:", ba, type(ba))
    ```

### 11. Memoryview (`memoryview`)
Bina copy kiye binary data ko access karna.
*   **Real Website Use-case:** 
    *   Web servers par badi video files ya PDF files ko bina server memory block kiye stream karna.
*   **Code:**
    ```python
    mv = memoryview(bytes([65,66,67]))
    print("MEMORYVIEW:", list(mv), type(mv))
    ```

### 12. Complex (`complex`)
Real + Imaginary numbers.
*   **Real Website Use-case:** 
    *   Website par chalne wale complex 3D graphics/animations (WebGL calculations) ya interactive math calculators.
*   **Code:**
    ```python
    z = 4 + 3j
    print("COMPLEX:", z, type(z))
    ```

## 🔄 Type Conversion (Real Example)

Websites me jab user koi input box me type karta hai (jaise Age ya Price), toh wo humesha **String (`str`)** ke roop me milta hai. Uske upar calculations karne ke liye hume conversion karna padta hai:

```python
# User ne form me input dala: "5" (String)
input_quantity = "5" 

# Calculate karne ke liye convert kiya Integer me:
quantity = int(input_quantity) # now 5 (Integer)

# Total cost check karne ke liye:
total_cost = quantity * 150 # 5 * 150 = 750
```
