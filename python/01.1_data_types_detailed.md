# Python Data Types — Easy Study Notes (Hinglish) 🐍

## Data Type Kya Hota Hai?

**Data Type** batata hai ki variable ke andar kis type ka data store hai.

Socho variable ek **dabba** hai, aur data type batata hai us dabbe me kya rakha hai — jaise:

* number
* text
* true/false
* list of items

---

## Python Data Types with Real Website Examples

### 1) Integer (`int`)

**Whole number** hota hai, decimal nahi hota.

**Use in websites:**

* cart items count
* likes count
* user ID

```python
age = 20
print("INTEGER:", age, type(age))
```

---

### 2) Float (`float`)

**Decimal number** hota hai.

**Use in websites:**

* product price
* rating
* location coordinates

```python
price = 99.99
print("FLOAT:", price, type(price))
```

---

### 3) String (`str`)

**Text** hota hai.

**Use in websites:**

* user name
* email
* search text

```python
name = "Rahul"
print("STRING:", name, type(name))
```

---

### 4) Boolean (`bool`)

Sirf 2 values hoti hain:

* `True`
* `False`

**Use in websites:**

* user logged in hai ya nahi
* product in stock hai ya nahi
* dark mode on hai ya nahi

```python
logged_in = True
print("BOOLEAN:", logged_in, type(logged_in))
```

---

### 5) List (`list`)

Multiple values ka group hota hai.
Isme values change ho sakti hain.

**Use in websites:**

* cart items
* blog tags
* students list

```python
fruits = ["Apple", "Banana", "Mango"]
fruits.append("Orange")
print("LIST:", fruits, type(fruits))
```

---

### 6) Tuple (`tuple`)

Multiple values ka group hota hai, lekin **change nahi hota**.

**Use in websites:**

* RGB color values
* map coordinates
* fixed settings

```python
resolution = (1920, 1080)
print("TUPLE:", resolution, type(resolution))
```

---

### 7) Set (`set`)

Isme **unique values** hoti hain. Duplicate values automatic remove ho jaati hain.

**Use in websites:**

* unique user IDs
* unique skills
* unique tags

```python
skills = {"Python", "SQL", "Python"}
print("SET:", skills, type(skills))
```

---

### 8) Dictionary (`dict`)

Data ko **key-value** form me store karta hai.

**Use in websites:**

* user profile
* student record
* product details

```python
student = {
    "name": "Rahul",
    "age": 20,
    "marks": 95
}
print("DICTIONARY:", student, type(student))
```

---

### 9) None (`NoneType`)

Iska matlab hota hai **kuch value nahi hai**.

**Use in websites:**

* empty field
* optional value missing
* coupon not applied

```python
result = None
print("NONE:", result, type(result))
```

---

### 10) Bytes (`bytes`) and Bytearray (`bytearray`)

Ye binary data ke liye use hote hain.

**Use in websites:**

* image file data
* file upload data
* network data

```python
b = b"ABC"
ba = bytearray(b"ABC")

print("BYTES:", b, type(b))
print("BYTEARRAY:", ba, type(ba))
```

---

### 11) Memoryview (`memoryview`)

Binary data ko **bina copy kiye** access karne ke liye.

**Use in websites:**

* large file handling
* streaming data
* efficient memory use

```python
mv = memoryview(bytes([65, 66, 67]))
print("MEMORYVIEW:", list(mv), type(mv))
```

---

### 12) Complex (`complex`)

Real number + imaginary number.

**Use in websites:**

* math calculations
* scientific computing
* advanced graphics

```python
z = 4 + 3j
print("COMPLEX:", z, type(z))
```

---

## Type Conversion

Kabhi-kabhi input **string** me aata hai.
Usko number me convert karna padta hai.

```python
input_quantity = "5"
quantity = int(input_quantity)

total_cost = quantity * 150
print("Total Cost:", total_cost)
```

---

## Final Summary

Python me mostly ye data types use hote hain:

* `int` = whole number
* `float` = decimal number
* `str` = text
* `bool` = True/False
* `list` = changeable group
* `tuple` = fixed group
* `set` = unique values
* `dict` = key-value data
* `None` = empty value
