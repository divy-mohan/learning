# 🐍 Python Introduction

## Python Kya Hai?

Python ek **High-Level**, **Interpreted** aur **General Purpose Programming Language** hai.

Simple shabdon me:

> Python ek language hai jisse hum computer ko instructions dete hain ki usse kya kaam karna hai.

Jaise hum insaan Hindi ya English me baat karte hain, waise hi computer se baat karne ke liye Programming Languages ka use karte hain. Python unhi languages me se ek hai.

---

## Real Life Example

Socho tumhare paas ek Robot hai.

Agar tum usse bolo:

- Room saaf karo
- Light on karo
- Gate band karo

To Robot tabhi ye kaam karega jab usse tumhari language samajh aaye.

Computer bhi bilkul aisa hi hota hai.

Python ek medium hai jiske through hum computer ko instructions dete hain.
